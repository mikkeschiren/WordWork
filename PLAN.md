# Word Work

Detta är en ordbehandlare som kan köras som docker container.

Den ska använda de existerande paket etc. som behövs för att det ska fungera.

Den ska använda rätt programeringsspråk för uppgiften.

Docker containern ska vara baserad på Wolfi OS från Chainguard.

## Gränssnitt

Ett enkelt harmoniskt gränssnitt, som FocusWriter och liknande verktyg.

## Funktionalitet

- Stavningskontroll
- Synonymer
- Lix-liknande funktion (se lix.se)
- Ordfrekvensräknare (se till exempel: https://www.prefix.nu/text-statistik.html)
- Möjlighet att spara i markdown, docx, open office etc.
- Fokus är ordbehandling, behövs inget stöd för bilder, tabeller etc.
- Tänkta användaren är kultur journalist och författare
- Möjlighet att chatta med AI för förbättringar i texten. AI ska aldrig skriva förbättringar i texten, bara föreslå.
